# Linux System Monitoring and Automation

## Project Overview
This is a beginner-level DevOps project that uses Bash scripting to monitor Linux system resources.

## Tools Used
- Ubuntu Linux
- Bash Shell Scripting
- GitHub

## Project Features
- Displays date and time
- Checks system uptime
- Displays memory usage
- Checks disk space
- Lists top CPU-consuming processes

## How to Run
Open the Ubuntu terminal and run:

```bash
chmod +x scripts/system-monitor.sh
./scripts/system-monitor.sh
```

## Learning Outcomes
- Linux command-line operations
- Bash scripting fundamentals
- System monitoring
- GitHub repository management
